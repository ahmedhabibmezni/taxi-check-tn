These WOFF2 web subsets are static instances of the original variable fonts:
Bricolage Grotesque: weight 400/700, width 100, optical size 14.
Literata: weight 600, optical size 48.
Noto Sans Arabic: weight 400/700, width 100.
Latin covers basic/extended Latin, punctuation, currency and interface signs.
Arabic additionally retains Arabic blocks, marks, shaping and positioning tables.
All layout features were retained. Uncovered scripts use local system fallbacks.
No remote font service is required.
